# yibinsun.github.io

Static personal academic website for Yibin Sun, published with GitHub Pages.

## Structure

- `index.html` contains the current public homepage and content.
- `cv/index.html` contains the web CV.
- `assets/css/site.css` contains the homepage styles.
- `assets/yibin-headshot.jpeg` is the optimized profile image used on the homepage.
- `code/heitorgomes.com/` is an imported reference snapshot and is not linked from the public homepage.

## Preview locally

From the repository root, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
